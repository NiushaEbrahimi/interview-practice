# Research Brief: Vercel AI SDK

**Date**: 2026-07-18
**Audience**: Developer using React (Vite) + Django REST backend (NOT Next.js)
**Goal**: Comprehensive understanding of Vercel AI SDK — architecture, capabilities, integration patterns, and how to use it outside the Next.js ecosystem.

## Scope

### In-scope
- What Vercel AI SDK is and its core architecture
- Frontend (React/Vue/Svelte) hooks and streaming utilities
- Backend integration patterns (non-Next.js, e.g. Python/Express/etc.)
- Supported AI providers (OpenAI, Anthropic, Google, etc.)
- Streaming and UI integration capabilities
- Tool calling / function calling support
- How it compares to raw API calls or alternatives
- Practical setup in a Vite + Django project

### Out-of-scope
- Deep Next.js-specific features (App Router, server components)
- Pricing details for AI providers
- General AI/LLM tutorials

## Assumptions
- User wants to potentially integrate AI features into their existing React+Django app
- They need to know if Vercel AI SDK is a good fit and how to wire it up without Next.js
- Django backend serves as the API layer; frontend is Vite-based React

## Depth: standard
